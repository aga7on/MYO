# 🧪 Инструкции по тестированию MYO Furniture Creator

## 📋 Пошаговое тестирование

### 1. Проверка установки датапака
```
/datapack list
```
**Ожидаемый результат:** В списке должен быть "MYO_Furniture_Creator" со статусом "enabled"

### 2. Перезагрузка датапака
```
/reload
```
**Ожидаемый результат:** Должно появиться сообщение "[MYO] Furniture Creator загружен!"

### 3. Тестирование простой функции
```
/function myo:test
```
**Ожидаемый результат:** Сообщение "MYO Datapack работает!" и зеленый текст "✅ Датапак MYO работает корректно!"

### 4. Тестирование основных команд
```
/function myo:give_creator
```
**Ожидаемый результат:** Получение сундука с названием "Создатель Мебели"

```
/function myo:help
```
**Ожидаемый результат:** Отображение справки с золотыми разделителями и цветным текстом

### 5. Проверка автодополнения
Начните вводить:
```
/function myo:
```
**Ожидаемый результат:** Должны появиться варианты: give_creator, help, load, test, tick и другие

### 6. Проверка scoreboard
```
/scoreboard objectives list
```
**Ожидаемый результат:** Должны быть видны цели: myo_data, myo_menu, myo_editor, myo_temp, myo_page, myo_pos_x, myo_pos_y, myo_pos_z

## 🔧 Диагностика проблем

### Если команды не работают:

#### Проблема 1: "Unknown function"
**Причина:** Датапак не загружен или неправильно установлен
**Решение:**
1. Проверьте структуру папок (см. ниже)
2. Выполните `/reload`
3. Проверьте `/datapack list`

#### Проблема 2: Датапак не в списке
**Причина:** Неправильная установка
**Решение:**
1. Убедитесь, что папка `MYO_Furniture_Creator` находится в `saves/[мир]/datapacks/`
2. Проверьте, что файл `pack.mcmeta` существует и содержит `pack_format: 71`

#### Проблема 3: Синтаксические ошибки
**Причина:** Неправильный формат команд
**Решение:**
1. Проверьте логи игры на ошибки
2. Убедитесь, что используется Minecraft 1.21.5+

## 📁 Правильная структура

```
saves/
└── [ваш_мир]/
    └── datapacks/
        └── MYO_Furniture_Creator/
            ├── pack.mcmeta (pack_format: 71)
            └── data/
                ├── minecraft/
                │   └── tags/
                │       └── functions/
                │           ├── load.json
                │           └── tick.json
                └── myo/
                    └── functions/
                        ├── give_creator.mcfunction
                        ├── help.mcfunction
                        ├── load.mcfunction
                        ├── test.mcfunction
                        ├── tick.mcfunction
                        └── [другие папки и файлы...]
```

## ✅ Контрольный список

- [ ] Minecraft версии 1.21.5 или новее
- [ ] Датапак в правильной папке
- [ ] pack.mcmeta содержит pack_format: 71
- [ ] Выполнена команда `/reload`
- [ ] Датапак появляется в `/datapack list`
- [ ] Команда `/function myo:test` работает
- [ ] Команда `/function myo:give_creator` работает
- [ ] Команда `/function myo:help` работает
- [ ] Автодополнение `/function myo:` показывает функции

## 📞 Если ничего не помогает

1. Полностью перезапустите Minecraft
2. Создайте новый тестовый мир
3. Установите датапак в новый мир
4. Проверьте логи игры на ошибки
5. Убедитесь, что у вас права администратора/OP в мире

**Если все тесты пройдены успешно, датапак готов к использованию! 🎉**
