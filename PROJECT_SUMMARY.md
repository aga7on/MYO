# MYO Furniture Creator - Сводка проекта

## 📋 Обзор проекта

**MYO Furniture Creator** - это полнофункциональный датапак для Minecraft, который позволяет игрокам создавать собственную мебель с помощью интуитивного 3D-редактора прямо в игре. Система основана на концепции пиксельного редактирования, где каждый блок мебели состоит из маленьких "пикселей" размером 1/16 от обычного блока.

## 🎯 Ключевые особенности

### ✨ Основной функционал
- **3D-редактор в игре** с визуальным курсором
- **Пиксельная точность** (16x16x16 сетка)
- **Интуитивное управление** через хотбар
- **Система сохранения** в организованные списки
- **Экспорт/импорт** для обмена творениями
- **Настройка текстур** из доступных блоков
- **Свойства блоков** (осязаемость, возможность сесть, свечение)

### 🎨 Дополнительные возможности
- **Готовые примеры** (стул, стол)
- **Шаблоны** для быстрого создания
- **Система отмены** действий
- **Встроенная справка** и руководства
- **Визуальные эффекты** и частицы
- **Многостраничное меню** управления

## 🎮 Как использовать

### Быстрый старт
1. **Установка**:
   ```batch
   # Запустите мастер установки
   MASTER_SETUP.bat
   
   # Выберите опцию 1 (Быстрая установка)
   ```

2. **В игре**:
   ```mcfunction
   # Скопируйте папку MYO_Furniture_Creator в datapacks
   # Используйте /reload
   # Получите создатель: /function myo:give_creator
   ```

3. **Создание мебели**:
   - Возьмите создатель в руку
   - Щелкните правой кнопкой
   - Выберите "Создание Мебели"
   - Поставьте основу и начинайте творить!

### Управление в редакторе

#### Страница 1 (Основное управление)
- **Слот 1-6**: Движение курсора (вверх/вниз/влево/вправо/вперед/назад)
- **Слот 7**: Установить блок
- **Слот 8**: Отменить последнее действие
- **Слот 9**: Переход на страницу 2

#### Страница 2 (Дополнительные функции)
- **Слот 1**: Вернуться на страницу 1
- **Слот 2**: Выбор текстуры
- **Слот 3**: Настройка свойств блока
- **Слот 4**: Сохранение мебели

## 🔧 Технические детали

### Системные требования
- **Minecraft**: Java Edition 1.19+
- **Формат датапака**: 15
- **Команды**: Должны быть включены
- **Права**: Администратор (для установки)

- **Скорборды**: 8 различных objectives

- **Максимум блоков**: 4096 на мебель
- **Автоочистка**: Каждые 5 минут
- **Оптимизация частиц**: Только для ближайших игроков
- **Кэширование**: Storage для часто используемых данных
