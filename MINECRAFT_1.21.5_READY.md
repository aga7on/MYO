# 🎉 MYO Furniture Creator - Готов для Minecraft 1.21.5!

## ✅ Что исправлено

### 📦 Формат датапака
- **pack_format**: Обновлен с 48 на **71** для полной совместимости с Minecraft 1.21.5

### 🔧 Синтаксис команд
- **Текстовые компоненты**: Все команды `tellraw` и `title` переведены с JSON на SNBT
- **Компоненты предметов**: Все `custom_name` и `lore` используют новый SNBT синтаксис
- **События**: `clickEvent` → `click_event`, `hoverEvent` → `hover_event`
- **NBT селекторы**: Обновлены для совместимости с 1.21.5

### 📝 Примеры изменений

#### Старый синтаксис (1.21.4 и ранее):
```mcfunction
tellraw @s [{"text":"Привет","color":"green"}]
give @s chest[custom_name='[{"text":"Создатель","color":"gold"}]']
```

#### Новый синтаксис (1.21.5):
```mcfunction
tellraw @s [{text:'Привет',color:'green'}]
give @s chest[custom_name={text:'Создатель',color:'gold'}]
```

## 🚀 Установка

### 1. Скачайте датапак
Скачайте папку `MYO_Furniture_Creator` из этого репозитория.

### 2. Установите в мир
1. Откройте папку вашего мира Minecraft
2. Перейдите в папку `datapacks`
3. Поместите туда папку `MYO_Furniture_Creator`

### 3. Активируйте датапак
В игре выполните команды:
```
/reload
/function myo:give_creator
```

## 🎮 Использование

### Основные команды:
- `/function myo:give_creator` - Получить создатель мебели
- `/function myo:help` - Справка по использованию
- `/reload` - Перезагрузить датапак

### Как создать мебель:
1. Получите "Создатель Мебели" командой `/function myo:give_creator`
2. Щелкните правой кнопкой мыши по предмету
3. Выберите "Создание Мебели" (бумага)
4. Поставьте прозрачный блок для начала редактирования
5. Используйте слоты 1-9 для управления 3D-редактором

### Управление в редакторе:
- **Слоты 1-6**: Движение курсора (вверх/вниз/влево/вправо/вперед/назад)
- **Слот 7**: Установить блок
- **Слот 8**: Отменить последнее действие
- **Слот 9**: Следующая страница инструментов

## 🐛 Устранение неполадок

### Команды не работают?
1. Убедитесь, что у вас **Minecraft 1.21.5** или новее
2. Проверьте, что читы включены: `/gamerule sendCommandFeedback true`
3. Перезагрузите датапак: `/reload`

### Датапак не загружается?
1. Проверьте структуру папок
2. Убедитесь, что файл `pack.mcmeta` содержит `pack_format: 71`
3. Проверьте права доступа к папке datapacks

### Меню не открывается?
1. Убедитесь, что вы держите правильный предмет
2. Попробуйте получить новый создатель: `/function myo:give_creator`
3. Проверьте, что вы щелкаете правой кнопкой мыши
