# Тест датапака MYO Furniture Creator

## Шаги для проверки:

### 1. Проверьте установку датапака
В игре выполните команду:
```
/datapack list
```
Должен появиться датапак "MYO_Furniture_Creator" в списке включенных.

### 2. Перезагрузите датапак
```
/reload
```
После этого должно появиться сообщение "[MYO] Furniture Creator загружен!"

### 3. Проверьте доступность функций
Попробуйте автодополнение команды:
```
/function myo:
```
Должны появиться доступные функции: give_creator, help, load, tick и другие.

### 4. Если функции не видны, попробуйте:
```
/function myo:load
```
Это должно принудительно загрузить датапак.

### 5. Альтернативная проверка
Попробуйте команду:
```
/scoreboard objectives list
```
Если датапак загружен, должны быть видны цели: myo_data, myo_menu, myo_editor и другие.

## Возможные проблемы:

1. **Датапак не в правильной папке**: Убедитесь, что папка MYO_Furniture_Creator находится в папке datapacks вашего мира.

2. **Неправильные права доступа**: На некоторых системах могут быть проблемы с правами доступа к файлам.

3. **Кэш игры**: Попробуйте полностью перезапустить Minecraft.

4. **Версия игры**: Убедитесь, что у вас Minecraft 1.21.5 или новее.

## Структура должна быть:
```
saves/
└── [ваш_мир]/
    └── datapacks/
        └── MYO_Furniture_Creator/
            ├── pack.mcmeta
            └── data/
                ├── minecraft/
                │   └── tags/
                │       └── functions/
                │           ├── load.json
                │           └── tick.json
                └── myo/
                    └── functions/
                        ├── give_creator.mcfunction
                        ├── help.mcfunction
                        ├── load.mcfunction
                        └── [другие файлы...]
```
