# 🔧 Исправление для Minecraft 1.21

## ❌ Проблема
Команда `/function myo:give_creator` не распознается в Minecraft 1.21

## ✅ Решение

### Причина
Minecraft 1.21 требует формат датапака **48**, а наш датапак был создан с форматом **15**.

### Быстрое исправление

#### Вариант 1: Замените файл pack.mcmeta
1. Откройте файл `MYO_Furniture_Creator/pack.mcmeta`
2. Замените содержимое на:
```json
{
  "pack": {
    "pack_format": 48,
    "description": "MYO Furniture Creator - Create your own custom furniture!"
  }
}
```

#### Вариант 2: Скачайте исправленную версию
Используйте папку `MYO_Furniture_Creator_1.21` из репозитория.

### Пошаговая инструкция

1. **Удалите старую версию** из папки datapacks
2. **Скопируйте исправленную версию** `MYO_Furniture_Creator_1.21`
3. **Переименуйте** её в `MYO_Furniture_Creator`
4. **В игре выполните**:
   ```
   /reload
   ```
5. **Проверьте загрузку**:
   ```
   /datapack list
   ```
6. **Получите создатель**:
   ```
   /function myo:give_creator
   ```

### Дополнительные проверки

#### Убедитесь, что команды включены
1. Откройте мир в режиме **Творчество** или с **читами**
2. Или включите команды в настройках мира

#### Проверьте структуру папок
Правильная структура:
```
.minecraft/
└── saves/
    └── [ИМЯ_МИРА]/
        └── datapacks/
            └── MYO_Furniture_Creator/
                ├── pack.mcmeta
                └── data/
                    ├── minecraft/
                    └── myo/
```

#### Проверьте загрузку датапака
После `/reload` должно появиться сообщение:
```
[MYO] Furniture Creator загружен! [Помощь]
```

### Если проблема остается

1. **Проверьте логи** на наличие ошибок
2. **Убедитесь**, что файлы не повреждены
3. **Попробуйте** создать новый мир для тестирования
4. **Проверьте права доступа** к файлам

### Команды для проверки
```mcfunction
/datapack list                    # Список датапаков
/datapack list enabled           # Включенные датапаки
/function myo:help              # Справка (если датапак загружен)
/function myo:give_creator      # Получить создатель мебели
```

---

**После исправления датапак должен работать корректно в Minecraft 1.21!**
