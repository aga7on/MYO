## 📋 Быстрый старт

### Для нетерпеливых:
1. **Скачайте** все файлы
2. **Запустите** `MASTER_SETUP.bat` (Windows) или `./setup_datapack.sh` (Linux/Mac)
3. **Скопируйте** `MYO_Furniture_Creator` в `datapacks`
4. **В игре**: `/reload` → `/function myo:give_creator`
5. **Начинайте творить!** 🎨

### Для изучающих:
1. **Прочитайте** `README.md` для полного понимания
2. **Изучите** `INSTALLATION_GUIDE.md` для детальной установки
3. **Ознакомьтесь** с `TECHNICAL_DOCS.md` для разработки
4. **Попробуйте** примеры и шаблоны
5. **Создавайте** собственные шедевры! ✨
