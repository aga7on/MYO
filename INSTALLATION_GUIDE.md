## ⚡ Быстрая установка

### Для Windows
1. **Скачайте все файлы** из репозитория
2. **Запустите** `MASTER_SETUP.bat`
3. **Выберите опцию 1** (Быстрая установка)
4. **Скопируйте** папку `MYO_Furniture_Creator` в `datapacks`
5. **В игре**: `/reload` → `/function myo:give_creator`

### Для Linux/Mac
1. **Скачайте все файлы** из репозитория
2. **Запустите** `./setup_datapack.sh`
3. **Скопируйте** папку `MYO_Furniture_Creator` в `datapacks`
4. **В игре**: `/reload` → `/function myo:give_creator`

## 📖 Подробная установка

### Шаг 1: Выбор версии установки

#### Windows пользователи
У вас есть несколько вариантов установки:

```batch
MASTER_SETUP.bat          # Интерактивный мастер (рекомендуется)
├── Опция 1: Быстрая установка (все функции + примеры)
├── Опция 2: Базовая установка (только основные функции)
├── Опция 3: Расширенная установка (+ визуальные эффекты)
├── Опция 4: Полная установка (+ система списков)
└── Опция 5: С примерами (полная + готовые шаблоны)

# Или запустите напрямую:
setup_datapack.bat         # Базовая версия
advanced_setup.bat         # Расширенная версия
complete_setup.bat         # Полная версия
examples_and_templates.bat # Версия с примерами
```

#### Linux/Mac пользователи
```bash
./setup_datapack.sh       # Базовая версия (пока единственная)
```

### Шаг 2: Запуск установки

#### Интерактивный мастер (Windows)
1. **Двойной клик** на `MASTER_SETUP.bat`
2. **Выберите нужную опцию** (рекомендуется опция 1)
3. **Дождитесь завершения** установки
4. **Нажмите любую клавишу** для создания документации

#### Прямой запуск (Windows)
```batch
# Для полной функциональности
examples_and_templates.bat
```

#### Linux/Mac
```bash
# Сделайте файл исполняемым
chmod +x setup_datapack.sh

# Запустите установку
./setup_datapack.sh
```

### Шаг 3: Результат установки

После успешной установки у вас будет:
```
📁 MYO_Furniture_Creator/     # Готовый датапак
├── pack.mcmeta              # Метаданные датапака
└── data/                    # Данные датапака
    ├── minecraft/           # Теги функций
    └── myo/                 # Основные функции
        ├── functions/       # Все функции системы
        ├── advancements/    # Достижения (если есть)
        ├── recipes/         # Рецепты (если есть)
        └── loot_tables/     # Таблицы лута (если есть)
```

## 🎮 Установка в игре

### Шаг 1: Копирование датапака
1. **Найдите папку вашего мира**:
   ```
   Windows: %appdata%\.minecraft\saves\[ИМЯ_МИРА]\datapacks\
   Mac: ~/Library/Application Support/minecraft/saves/[ИМЯ_МИРА]/datapacks/
   Linux: ~/.minecraft/saves/[ИМЯ_МИРА]/datapacks/
   ```

2. **Скопируйте папку** `MYO_Furniture_Creator` в папку `datapacks`

3. **Структура должна быть**:
   ```
   saves/
   └── [ИМЯ_МИРА]/
       └── datapacks/
           └── MYO_Furniture_Creator/
               ├── pack.mcmeta
               └── data/
   ```

### Шаг 2: Активация в игре
1. **Запустите мир** или **войдите в существующий**
2. **Откройте чат** (клавиша T)
3. **Введите команду**: `/reload`
4. **Дождитесь сообщения** о загрузке датапака

### Шаг 3: Получение создателя мебели
1. **Введите команду**: `/function myo:give_creator`
2. **Получите предмет** "Создатель Мебели" в инвентарь
3. **Готово!** Можете начинать создавать мебель

## 🎯 Первое использование

### Открытие меню
1. **Возьмите** "Создатель Мебели" в руку
2. **Щелкните правой кнопкой мыши**
3. **Откроется главное меню** с опциями

### Создание первой мебели
1. **Выберите** "Создание Мебели" (бумага)
2. **Получите основу** (прозрачный блок)
3. **Поставьте основу** в нужном месте
4. **Используйте хотбар** для управления курсором
5. **Создавайте мебель** блок за блоком

### Управление в редакторе
#### Страница 1 (Основное)
- **1-6**: Движение курсора
- **7**: Установить блок
- **8**: Отменить
- **9**: Следующая страница

#### Страница 2 (Дополнительно)
- **1**: Предыдущая страница
- **2**: Выбор текстуры
- **3**: Свойства блока
- **4**: Сохранить мебель

## 🔧 Решение проблем

### Датапак не загружается

#### Проблема: Нет сообщения о загрузке
**Решение:**
1. Проверьте путь к папке datapacks
2. Убедитесь, что структура папок правильная
3. Проверьте, что команды включены в мире
4. Попробуйте `/reload` еще раз

#### Проблема: Ошибка "Unknown function"
**Решение:**
1. Убедитесь, что файл `pack.mcmeta` существует
2. Проверьте формат JSON в `pack.mcmeta`
3. Убедитесь, что папка называется именно `MYO_Furniture_Creator`

### Создатель мебели не работает

#### Проблема: Команда `/function myo:give_creator` не работает
**Решение:**
1. Убедитесь, что датапак загружен (`/reload`)
2. Проверьте права администратора
3. Попробуйте `/function myo:help`

#### Проблема: Меню не открывается
**Решение:**
1. Убедитесь, что держите правильный предмет
2. Попробуйте получить новый создатель
3. Проверьте, что у вас есть права на использование команд

### Редактор не работает

#### Проблема: Хотбар не заполняется
**Решение:**
1. Убедитесь, что поставили основу (барьер)
2. Попробуйте выйти и войти в редактор заново
3. Проверьте, что инвентарь не заполнен

#### Проблема: Курсор не отображается
**Решение:**
1. Убедитесь, что частицы включены в настройках
2. Подойдите ближе к области редактирования
3. Попробуйте переместить курсор

### Производительность

#### Проблема: Лаги при использовании
**Решение:**
1. Уменьшите настройки частиц
2. Закройте другие ресурсоемкие приложения
3. Используйте базовую версию датапака

#### Проблема: Долгая загрузка
**Решение:**
1. Увеличьте `maxCommandChainLength` в настройках мира
2. Перезапустите Minecraft
3. Попробуйте на новом мире
