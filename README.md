## 🎯 Описание

**MYO Furniture Creator** - это революционный датапак для Minecraft, который превращает игру в полноценную студию дизайна мебели. Создавайте уникальные предметы мебели с пиксельной точностью, настраивайте их свойства и делитесь творениями с друзьями!

## ✨ Ключевые особенности

- 🎨 **3D-редактор в игре** с визуальным курсором
- 🔧 **Пиксельная точность** (16x16x16 сетка)
- 🎮 **Интуитивное управление** через хотбар
- 💾 **Система сохранения** в организованные списки
- 🔄 **Экспорт/импорт** для обмена творениями
- 🎨 **Настройка текстур** из доступных блоков
- ⚙️ **Свойства блоков** (осязаемость, возможность сесть, свечение)
- 📚 **Готовые примеры** и шаблоны для быстрого старта

## 🚀 Быстрая установка

### Автоматическая установка (Рекомендуется)
1. Скачайте все файлы из репозитория
2. Запустите `complete_setup.bat` (для полной функциональности)
3. Скопируйте созданную папку `MYO_Furniture_Creator` в папку `datapacks` вашего мира
4. В игре используйте команду `/reload`
5. Получите создатель мебели: `/function myo:give_creator`

### Варианты установки
- `setup_datapack.bat` - Базовая версия
- `advanced_setup.bat` - Расширенная версия с визуальными эффектами
- `complete_setup.bat` - Полная версия со всеми функциями

## 🎮 Как использовать

### Начало работы
1. Получите создатель мебели: `/function myo:give_creator`
2. Возьмите предмет в руку и щелкните правой кнопкой мыши
3. Откроется главное меню с опциями

### Главное меню
- **📄 Бумага (Создание Мебели)** - Начать создание новой мебели
- **📚 Книга (Мои Творения)** - Просмотр созданной мебели
- **💎 Экспорт** - Экспорт ваших творений
- **💚 Импорт** - Импорт мебели от других игроков

### Создание мебели

#### Шаг 1: Установка основы
1. Выберите "Создание Мебели"
2. Получите прозрачный блок (барьер)
3. Поставьте его в нужном месте
4. Автоматически откроется редактор

#### Шаг 2: Редактирование (Страница 1)
Используйте слоты хотбара для управления:
- **Слот 1**: ⬆️ Вверх
- **Слот 2**: ⬇️ Вниз  
- **Слот 3**: ⬅️ Влево
- **Слот 4**: ➡️ Вправо
- **Слот 5**: ⬆️ Вперед
- **Слот 6**: ⬇️ Назад
- **Слот 7**: 🔴 Установить блок
- **Слот 8**: ↩️ Отменить действие
- **Слот 9**: 📄 Следующая страница

#### Шаг 3: Дополнительные функции (Страница 2)
- **Слот 1**: 📚 Вернуться на первую страницу
- **Слот 2**: 🎨 Установить текстуру
- **Слот 3**: ⚙️ Свойства блока
- **Слот 4**: 💾 Сохранить мебель

### Система текстур
В меню текстур вы можете выбрать внешний вид для ваших блоков:
- Дубовые доски
- Камень
- Железный блок
- Золотой блок
- Алмазный блок
- Изумрудный блок

### Свойства блоков
Настройте поведение ваших блоков:
- **Осязаемость**: Могут ли игроки стоять на блоке
- **Возможность сесть**: Можно ли использовать как стул
- **Свечение**: Излучает ли блок свет

### Система сохранения
Сохраняйте мебель в организованные списки:

#### Команды для работы с листами:
- `/function myo:commands/newlist` - Создать новый лист
- `/function myo:commands/addlist` - Добавить в существующий лист  
- `/function myo:commands/renamelist` - Переименовать лист

#### Формат команд в чате:
- Создание листа: `Название Листа`
- Добавление: `название_листа название_предмета`
- Переименование: `старое_название новое_название`

## 🎨 Принцип работы

### Концепция пиксельного редактора
Мебель создается путем размещения маленьких "пикселей" внутри блока размером 16x16x16. Каждый пиксель представляет собой 1/16 часть блока, что позволяет создавать детализированные модели.

### Визуальная система
- **Красный курсор**: Показывает текущую позицию для размещения
- **Синие блоки**: Уже размещенные элементы мебели
- **Частицы**: Визуальные эффекты для лучшего понимания позиции

### Система тегов
Все элементы системы используют уникальные теги:
- `myo_base` - Основа для редактирования
- `myo_cursor` - Курсор позиции
- `myo_placed` - Размещенные блоки

## 🆘 Справка и поддержка

### Встроенная справка
Используйте `/function myo:help` для получения справки в игре

### Основные команды
- `/function myo:give_creator` - Получить создатель мебели
- `/function myo:help` - Показать справку
- `/reload` - Перезагрузить датапак

### Решение проблем

#### Датапак не загружается
1. Убедитесь, что папка находится в `datapacks`
2. Проверьте, что команды включены в мире
3. Используйте `/reload`

#### Редактор не работает
1. Убедитесь, что основа (барьер) установлена
2. Проверьте, что у вас есть права на использование команд
3. Попробуйте перезапустить редактор

#### Визуальные эффекты не отображаются
1. Убедитесь, что частицы включены в настройках
2. Подойдите ближе к области редактирования
3. Проверьте настройки производительности
